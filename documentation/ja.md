## 方法の版

APACHE II/Knaus 1985：12変数、年齢、慢性疾患、FiO₂による酸素化、診断別ロジスティックモデル

## 記載された計算式

APACHE II = 急性生理学スコア（12変数、各0～4点；Glasgowは15 − Glasgowとして加算）+年齢点 (≤ 44 = 0; 45–54 = 2; 55–64 = 3; 65–74 = 5; ≥ 75 = 6) + 慢性疾患（内科入院または緊急術後は5点、予定術後は2点）。

酸素化：FiO₂ ≥ 50%ではA–a較差を採点 \[FiO₂ × 713 − PaCO₂/0.8 − PaO₂\]: ≥ 500 = 4; 350–499 = 3; 200–349 = 2; \< 200 = 0. FiO₂ \< 50%ではPaO₂を採点： \> 70 = 0; 61–70 = 1; 55–60 = 3; \< 55 = 4. 急性腎不全ではクレアチニンの点数を2倍にします。

予測院内死亡率： ln\[R/(1 − R)\] = −3.517 + 0.146 × APACHE II + 0.603 （緊急手術の場合）+診断カテゴリーの重み。

## 限界・対象集団

1985年のAPACHE IIは、13病院の5815件のICU入院における院内死亡と関連付けられました。著者が記載した予後層別化は、スコアと正確な疾病記述を組み合わせます。合計点だけでは、その診断情報を再現できません。データ収集の時間枠、除外条件、この集団以外への適用可能性は、方法の全文で確認する必要があります。
