## 方法版本

APACHE II/Knaus 1985：12项变量；年龄；慢性疾病；按FiO₂评估氧合；诊断特异性逻辑回归模型

## 已记录的公式

APACHE II = 急性生理评分（12项变量，每项0至4分；Glasgow按15 − Glasgow计）+年龄分 (≤ 44 = 0; 45–54 = 2; 55–64 = 3; 65–74 = 5; ≥ 75 = 6) + 慢性疾病（内科入院或急诊术后5分；择期术后2分）。

氧合：FiO₂ ≥ 50%时，对A–a梯度评分 \[FiO₂ × 713 − PaCO₂/0.8 − PaO₂\]: ≥ 500 = 4; 350–499 = 3; 200–349 = 2; \< 200 = 0. FiO₂ \< 50%时，对PaO₂评分： \> 70 = 0; 61–70 = 1; 55–60 = 3; \< 55 = 4. 急性肾衰竭时肌酐分数加倍。

预测院内死亡率： ln\[R/(1 − R)\] = −3.517 + 0.146 × APACHE II + 0.603 （急诊手术时）+诊断类别权重。

## 限制与适用人群

1985年的APACHE II与13家医院5815次ICU入院的院内死亡有关。作者描述的预后分层结合评分与准确的疾病描述；单独的总分不能再现这些诊断信息。资料采集时间窗、排除条件及对该人群之外的适用性，需要核对完整方法。
